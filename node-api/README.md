# node-api

Публичный API заявок на кредит. Elysia + Drizzle + PostgreSQL.

## Запуск

```bash
pnpm install
pnpm db:migrate   # применить миграции из ./drizzle
pnpm dev
```

В Docker миграции запускаются автоматически перед стартом приложения.

## Команды

| Команда            | Описание                                                  |
| ------------------ | --------------------------------------------------------- |
| `pnpm dev`         | Запуск с watch-режимом                                    |
| `pnpm start`       | Запуск без watch                                          |
| `pnpm typecheck`   | Проверка TypeScript                                       |
| `pnpm db:generate` | Сгенерировать миграцию после изменения `src/db/schema.ts` |
| `pnpm db:migrate`  | Применить миграции                                        |
| `pnpm db:seed`     | Добавить тестовые заявки (если таблица пуста)             |
| `pnpm db:push`     | Быстро синхронизировать схему с БД (без файлов миграций)  |
| `pnpm format`      | Prettier                                                  |

## Переменные окружения

| Переменная              | Обязательна | По умолчанию            |
| ----------------------- | ----------- | ----------------------- |
| `DATABASE_URL`          | да          | —                       |
| `INTERNAL_API_KEY`      | да          | —                       |
| `PORT`                  | нет         | `3000`                  |
| `PYTHON_API_URL`        | нет         | `http://127.0.0.1:8000` |
| `PYTHON_API_TIMEOUT_MS` | нет         | `45000`                 |

Локально `.env` читается из корня репозитория (или из текущей директории).

## API

- `GET /requests`
- `GET /requests/:id`
- `POST /requests`
- `GET /health`

Документация OpenAPI — на `/`, JSON-спецификация — на `/json`.

`POST /requests` сохраняет заявку и вызывает `POST /assess` внутреннего
Python-сервиса с заголовком `X-Internal-Api-Key`. Результат оценки хранится в
`requests.assessment`; статус заявки выставляется по решению ML. Если сервис
недоступен, заявка сохраняется со статусом `Повторная проверка`.
